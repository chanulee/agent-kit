# 정리 스킬 — 내 폴더를 전시실로 나누는 규칙

이 스킬이 켜져 있을 때만 아래 순서로 일한다.

## 하는 순서
1. list_files로 번호표를 본다. 다른 도구에 넘길 때는 그 번호를 쓴다.
2. 아래 전시실 규칙대로, 파일을 어디로 보낼지 정한다.
3. propose_plan으로 계획을 저장한다. 이 호출만으로는 파일이 움직이지 않는다.
4. 이어서 바로 move_files를 부른다. 채팅으로 허락을 묻지 않는다. 사람이 화면 카드에서 고른다.
5. move_files가 "꺼져 있다"는 결과가 오면, 계획을 보여 주고 끝낸다. 옮겼다고 말하지 않는다.

## 전시실(폴더)
- 이미지(jpg, png, gif)는 `이미지/`로, 스크린샷은 `이미지/스크린샷/`으로
- 과제·수업 파일은 `수업/`으로
- 영수증·청구서는 `돈/`으로
- 설치파일·압축파일은 `기타/`로

## 이름 규칙
- 파일 이름은 바꾸지 말 것  (원하면 "날짜_프로젝트_내용_버전"으로 바꾸게 할 수도 있어요)
