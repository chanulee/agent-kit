# 06. 아직 모르는 것, 위험, 남은 결정

> 현재 공통 실습: 샘플은 사본 없이 저장소의 `sample_downloads/`에서 직접 사용합니다. **폴더 고르기 → 샘플 폴더 → 이 폴더 사용**으로 선택하며, 이동 결과·노트·갤러리도 같은 폴더에서 확인합니다. 아래 초기 설계의 사본 절차는 개인 폴더 사용에만 해당합니다. 현재 실행 안내는 [GUIDE 0-6](../GUIDE.md#0-6-화면과-실습-폴더)을 따릅니다.

> 개발을 시작하기 전에 이 목록부터 확인하세요. 위에서부터 중요한 순서입니다.

## 1. 아직 확인하지 않은 것

| # | 확인할 것 | 왜 중요한가 | 확인 방법 |
|---|---|---|---|
| Q1 | **Anthropic 모델로 시험 3종을 처음부터 끝까지 돌리기** | 학생 대부분이 Anthropic 키를 씀. 아직 한 번도 안 돌림 | `MODEL=anthropic:<모델 ID>`로 `prototype/tests` 실행 |
| Q2 | 수업용 Anthropic 모델 ID와 1인당 비용 | 비용 목표(약 5달러) 확인 | 시험 실행의 토큰 수로 계산 |
| Q3 | Tavily를 키 없이 16명이 동시에 쓰면 막히는가 | 키 없는 학생이 있을 수 있음 | 강의실 와이파이에서 여러 대로 동시 실행 |
| Q4 | `tavily-mcp`가 요구하는 Node 버전 | 학생 노트북 준비물 안내 | 깨끗한 Mac/Windows에서 설치 |
| Q5 | MCP 서버에 키를 넘길 때 기본 환경(PATH 등)이 빠지는가 | 빠지면 `npx`가 안 켜짐 | `TAVILY_API_KEY`를 넣고 `t1_web.py` 실행 |
| Q6 | Windows에서 OneDrive 안으로 옮겨진 다운로드 폴더 경로 | 사본 만들기가 실패할 수 있음 | Windows 노트북 2~3대에서 확인 |
| Q7 | Met API 호출 한도와 이미지 직접 연결 허용 여부 | 16명이 동시에 부름 | 문서 확인 + 동시 호출 시험. 대비로 캐시 |
| Q8 | `t3_met.py`를 v1.1 검색 주소로 고친 뒤 LLM까지 포함해 다시 돌리기 | 옛 주소는 지금 410(종료)을 돌려줌. 도구 부분만 확인함 | 유료 키로 실행 |
| Q9 | 10개 이동에 78초 → 한 번에 옮기는 도구로 얼마나 줄어드나 | 수업 시간 | 새 도구로 다시 측정 |
| Q10 | aisuite 트레이스 기록을 Loop Theater가 그대로 읽을 수 있나 | 개발 시간 절약 | aisuite 기록 기능으로 파일을 남겨 확인 |

## 2. 위험과 대비

| 위험 | 어떤 일이 생기나 | 미리 막기 | 수업 당일 대비 |
|---|---|---|---|
| 개인 파일 | 다운로드 폴더에 신분증, 통장, 계약서, 다른 사람 사진이 있음. 파일 이름과 앞부분이 클라우드 AI로 감 | 사본만 사용, 민감한 이름 자동 제외, 복사 전 목록 고르기, 이미지 비전은 기본 끔, 첫 장면에서 솔직하게 알림 | 샘플 폴더 사용(부끄러운 일이 아니라고 먼저 말함). 화면 공유는 동의할 때만 |
| 파일 사고 | 엉뚱한 곳으로 옮김, 이름 겹침 | 사본 안에서만, 삭제 도구 없음, 덮어쓰기 금지, 승인 후 실행, 되돌리기 기록 | 되돌리기. 최악이면 사본을 다시 만듦 |
| 호출 한도(429)와 서버 바쁨(503) | 응답이 늦거나 멈춘 것처럼 보임 | 유료 키, 턴 한도 8, 파일 60개 제한 | 화면에 대기 시간 표시, 리플레이 |
| 와이파이 / API 장애 | 아무것도 안 됨 | 오프라인 캐시, 녹화본 | Theater 리플레이로 진행, 짝과 화면 함께 보기 |
| Node가 없음 | Tavily MCP가 안 켜짐 | 사전 설치 안내, 미리 한 번 받아 두기 | 웹 장면은 리플레이 |
| 한글 파일명 | Mac에서 만든 한글 이름이 자모로 쪼개져 비교 실패 | 모든 이름을 같은 방식(NFC)으로 맞춤 | 샘플 폴더 |
| Cursor가 엔진을 고침 | 학생이 부탁했다가 키트가 망가짐 | Cursor 규칙 파일에 "엔진 수정 금지" | 완성본으로 바꾸기, 처음 상태로 |
| 시간 초과 | 탐정 추리가 재미있어서 길어짐 | 장면마다 타이머 | 장면 1을 시연으로, 장면 3을 리플레이로 |
