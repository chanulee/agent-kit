# 00. 용어 풀이 (처음 보는 말이 나오면 여기를 보세요)

> 현재 공통 실습: 샘플은 사본 없이 저장소의 `sample_downloads/`에서 직접 사용합니다. **폴더 고르기 → 샘플 폴더 → 이 폴더 사용**으로 선택하며, 이동 결과·노트·갤러리도 같은 폴더에서 확인합니다. 아래 초기 설계의 사본 절차는 개인 폴더 사용에만 해당합니다. 현재 실행 안내는 [GUIDE 0-6](../GUIDE.md#0-6-화면과-실습-폴더)을 따릅니다.

이 저장소의 문서는 이 표의 말을 씁니다. 어려운 말은 처음 나올 때 이 표로 연결합니다.

지금 돌아가는 키트의 기준은 [README](../README.md)입니다. 도구는 `tools/`이고, 화면의 L1~L4 스위치는 없습니다. 아래 문서 중 일부는 그 이전 설계를 그대로 적고 있습니다.

| 말 | 쉬운 뜻 | 예시 |
|---|---|---|
| **LLM** (대형 언어 모델) | 글을 읽고 글로 답하는 AI의 "뇌". Claude, Gemini 같은 것 | "지금 몇 시야?"라고 물으면 글로 답합니다. 하지만 시계를 볼 수는 없습니다 |
| **챗봇** | 말만 주고받는 AI. 스스로 무엇을 하지는 않습니다 | 내 폴더를 볼 수 없어서 "보통 다운로드 폴더에는…"이라고 짐작만 합니다 |
| **에이전트** | 목표를 받으면 스스로 할 일을 고르고, 도구로 실제로 해 보고, 결과를 보고 다음 일을 정하는 AI | "폴더를 정리해 줘" → 목록을 보고 → 계획을 세우고 → 허락을 받아 → 실제로 옮깁니다 |
| **도구** (tool) | 에이전트가 시켜 실제로 일을 시키는 함수. 모델은 어떤 도구를 쓸지 고르기만 하고, 실행은 프로그램이 합니다. 이 키트에서는 `tools/` 폴더입니다 | `list_files`(파일 목록), `write_file`(노트 만들기) |
| **루프** (loop) | "고르기 → 해 보기 → 결과 보기 → 다시 고르기"를 끝날 때까지 되풀이하는 것 | 탐정이 단서 하나를 보고, 그 단서 때문에 다음에 볼 파일을 바꿉니다 |
| **턴** / **턴 한도** | 루프 한 바퀴 / 몇 바퀴까지 돌지 정한 숫자(`max_turns`) | 턴 한도를 3으로 줄이면 탐정이 추리 도중에 멈춥니다 |
| **프롬프트** | AI에게 주는 글 지시 | "미술관 캡션처럼 2문장으로 써 줘" |
| **페르소나** (`persona.md`) | 에이전트의 캐릭터와 말투를 적은 파일 | "깐깐하지만 유머 있는 큐레이터" |
| **스킬** (`SKILL.md`) | 필요할 때만 꺼내 읽는 업무 매뉴얼. 평소엔 제목만 알고, 그 일을 할 때 본문을 읽습니다 | "내 파일 이름 규칙: 날짜_프로젝트_내용_버전" |
| **API** | 프로그램끼리 정해진 방식으로 정보를 주고받는 창구 | 메트로폴리탄 미술관 API에 "sunflowers"를 물으면 작품 목록을 돌려줍니다 |
| **API 키** | API를 쓸 때 내는 비밀 출입증. 남에게 보여 주면 안 됩니다 | `ANTHROPIC_API_KEY=...` (이 저장소에는 절대 넣지 않습니다) |
| **MCP** | 남이 만든 도구를 꽂는 표준 콘센트. 이 키트에서는 `mcp.json`에서 켜고 끕니다 | Tavily를 켜면 `web_search`, `web_read`가 생깁니다 |
| **MCP 서버** | MCP 콘센트에 꽂는 "공구" 프로그램 | `tavily-mcp` (웹 검색), filesystem 서버 (파일 다루기) |
| **하네스** (harness) | LLM을 감싸서 실제로 일하게 하는 틀. 루프 돌리기, 도구 연결, 기록 남기기, 허락 받기를 맡습니다. 말에 씌우는 마구처럼, 힘은 LLM이 내고 방향은 하네스가 잡습니다 | 이 키트의 "엔진"이 하네스입니다 |
| **사람 승인** (human-in-the-loop) | 중요한 행동 전에 사람에게 허락을 받는 자리 | 파일을 옮기기 전 계획표에 ✅/❌/✏️ |
| **워크플로** / **그래프** | 미리 정한 순서(길). 노드(칸)와 화살표로 그립니다 | 탐색 → 계획 → 승인 → 실행 → 전시 |
| **멀티에이전트** | 역할이 다른 에이전트 여럿이 나눠 일하는 것 | 큐레이터가 전시실을 꾸리면 도슨트가 해설을 붙입니다 |
| **부품** | 에이전트에 하나씩 더하는 설정. 도구, 스킬, 승인, MCP. 화면 🧩 또는 `agent.yaml` 한 줄 | 2단계에 `list_files`를 켜면 폴더를 보기 시작함 |
| **L1~L4** | 예전 화면의 단계 스위치. 지금 키트에는 없고, 부품을 하나씩 켜는 것으로 바뀌었습니다 | README의 수업 흐름 |
| **Loop Theater** | 에이전트가 지금 무엇을 하는지 실시간으로 보여 주는 화면 | 턴마다 카드 한 장. 지금 쓰는 손에 불이 켜짐 |
| **사본 폴더** | 원본을 복사한 연습용 폴더. 여기서만 파일을 옮깁니다 | `~/agent-workshop/exhibit_copy/` |
| **되돌리기** (undo) | 옮긴 파일을 원래 자리로 돌려놓기 | 옮긴 기록(`undo.json`)을 거꾸로 실행 |
| **공공 도메인** | 저작권이 없어 누구나 써도 되는 작품 | 반 고흐 「Sunflowers」 |
| **리플레이** | 미리 녹화한 실행 기록을 다시 틀기. 인터넷이 끊겨도 수업이 됩니다 | `replays/L3.jsonl` |
| **429 / 503** | 서버가 "너무 많이 불렀어요, 잠깐 기다려요"(429) / "지금 바빠요"(503)라고 답하는 신호 | 화면에 "23초 기다리는 중"이 뜹니다 |
| **설정 파일** | 버튼 대신 글로 적은 설정. 버튼을 누르면 이 파일이 바뀝니다 | `config.yaml`, `mcp.json` |
| **aisuite** | 여러 회사의 LLM을 같은 방식으로 부르게 해 주는 작은 파이썬 도구 모음. 이 키트의 바탕 | Claude와 Gemini를 설정 한 줄로 바꿉니다 |
| **Tavily** | AI용 웹 검색 서비스. 무료 키(월 1,000회, 카드 불필요)가 있습니다 | `tavily_search`(찾기), `tavily_extract`(페이지 읽기) |
| **Cursor** | AI에게 말로 부탁해 코드를 고칠 수 있는 편집기 | "갤러리를 어두운 미술관 벽 느낌으로 바꿔 줘" |
| **PR, 브랜치** | GitHub에서 고친 내용을 따로 모아 두고(브랜치) 합쳐 달라고 요청하는 것(PR) | 이 문서들은 `docs/initial-spec` 브랜치에 있습니다 |

## 문서에 나오는 표시

| 표시 | 뜻 |
|---|---|
| **MUST** | 꼭 있어야 함 |
| **SHOULD** | 있으면 좋음. 시간이 없으면 빼도 수업은 됨 |
| **COULD** | 선택 |
| **[확인함]** | 직접 실행해서 확인함 |
| **[확인 필요]** | 아직 직접 실행하지 않음 |

## 개발 문서에 가끔 나오는 말

| 말 | 쉬운 뜻 |
|---|---|
| 캐시 | 한 번 가져온 결과를 저장해 두고 다시 쓰는 것. 인터넷이 끊겨도 쓸 수 있음 |
| 컨텍스트 | AI에게 한 번에 보내는 글 전체(대화, 규칙, 도구 결과) |
| 토큰 | AI가 글을 세는 단위. 많을수록 비용과 시간이 늘어남 |
| 인자 | 도구에 넘기는 값. 예: `peek_file("포스터.pdf")`의 `"포스터.pdf"` |
| 환경 변수 / `.env` | 키 같은 비밀 값을 코드 밖에 따로 적어 두는 곳 |
| Node / `npx` | 일부 MCP 서버를 실행하는 프로그램 / 그 실행 명령 |
| `uv` | 파이썬 프로그램을 설치하고 실행하는 도구. 버전을 고정해 줌 |
| `localhost` | 내 노트북 안에서만 열리는 웹 주소 |
| 기록(trace, `trace.jsonl`) | 에이전트가 한 일을 한 줄씩 적은 파일. Loop Theater가 이것을 읽어 보여 줌 |
| 프레임워크 | 에이전트를 만들 때 쓰는 기본 틀(도구 모음). 예: aisuite, LangChain |
| NFC / NFD | 한글을 컴퓨터에 저장하는 두 방식. Mac은 가끔 자모로 쪼개 저장(NFD)해서 같은 이름이 다르게 보임 |
