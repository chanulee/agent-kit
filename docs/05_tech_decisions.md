## 1. 프레임워크: aisuite vs LangChain/LangGraph

프레임워크 = 에이전트를 만들 때 쓰는 기본 틀(하네스를 쉽게 만들게 도와주는 도구 모음).

| 기준 (5가 가장 좋음) | aisuite 0.2.0 | LangChain 1.x + LangGraph |
|---|---|---|
| 배우기 쉬움 | 5 | 3 |
| 루프가 눈에 보임 | 5 (직접 돌리는 방식도 가능) | 4 (루프가 안에 숨어 있음) |
| 다른 서비스와 연결(MCP) | 4 | 5 |
| 그래프(정해진 길) | 2 (직접 짜야 함) | 5 |
| 안정성 | 한 달에 한 번쯤 새 버전 | 이번 주에도 여러 번 새 버전 |
| 자료의 양 | 적음 | 많지만 옛 버전 자료가 섞여 헷갈림 |

점수는 문서를 읽고 매긴 판단입니다. 측정한 값이 아닙니다.

결정: **aisuite만 씁니다.**

| 이유 | 설명 |
|---|---|
| 목표가 "이해" | 학생이 루프를 눈으로 봐야 합니다. aisuite는 코드가 얇아서 Loop Theater에 그대로 보여 주기 쉽습니다 |
| 그래프는 그림으로 | 학생은 그래프를 만들지 않고 봅니다(보기 전용). 순서는 파이썬 코드로 짜면 충분합니다 |
| 버전 위험 | LangChain/LangGraph는 너무 자주 바뀝니다. 수업 전날 깨질 위험이 큽니다 |

예전 비교 문서(`archive/framework_comparison.md`)은 "aisuite + LangChain 함께 쓰기"를 권했습니다. 이후 설계에서 aisuite만 쓰기로 바꿨습니다.

aisuite에서 확인한 것:

| 내용 | 근거 |
|---|---|
| `max_turns`를 주면 도구 루프를 알아서 돌림 | 시험 3종 모두 이 방식으로 통과 [확인함] |
| MCP 서버 연결 기능(`MCPClient`)이 있음 | Tavily 연결 성공 [확인함] |
| **도구 안에서 오류가 나면 루프 전체가 멈춤** | aisuite 소스 `aisuite/utils/tools.py`의 도구 실행 부분이 오류를 다시 던짐 [확인함]. 그래서 모든 도구는 오류를 글(`"error: ..."`)로 돌려줘야 합니다 |

## 2. 웹 검색과 읽기

| 후보 | 결과 | 결정 |
|---|---|---|
| **Tavily MCP** (`npx -y tavily-mcp@latest`) | 키 없이 검색과 읽기 모두 됨. 도구 이름은 밑줄(`tavily_search`, `tavily_extract`) [확인함]. 시험 1회 41.7초 | **기본** |
| Fetch MCP | Node 22 이상 필요. 처음 실행할 때 설치 메시지가 연결을 깨뜨림 | 빼기. `tavily_extract`가 대신함 |
| DuckDuckGo MCP | 봇 차단으로 5회 중 2회 실패. 위키백과 문서를 못 가져옴 | 예비로만 |
| Playwright MCP | 진짜 브라우저가 움직여 가장 놀라움. 설치가 무거움 | 강사 시연만 |
| Claude 자체 웹 검색 | aisuite가 이 기능을 넘겨주지 않음 | 쓸 수 없음 |

학생에게 권할 것: Tavily 무료 키 받기(월 1,000크레딧, 카드 필요 없음). 키가 없어도 동작은 하지만, 16명이 같은 곳에서 키 없이 쓰면 막힐 수 있습니다 [확인 필요].

## 5. 그 밖의 결정

| 주제 | 결정 | 이유 |
|---|---|---|
| 수업 화면 | 웹앱 하나(왼쪽 채팅, 오른쪽 Loop Theater) | 터미널을 몰라도 됨. 버튼 → 파일로 자연스럽게 넘어감 |
| 화면 기술 | 설치 없는 HTML/JS, 파일은 모두 로컬 | 인터넷이 끊겨도 동작 |
| 노드 그래프 | 보기 전용 | 편집기는 만들기 어렵고 수업 목표가 아님 |
| 파일 삭제 | 도구를 만들지 않음 | 안전 |
| 닮은 작품 고르기 | 글(제목·재료·태그) 비교가 기본, 이미지 비교는 동의할 때만 | 비용과 개인정보 |
| 재시도 대기 | 화면에 보여 줌 | 기다리는 이유를 알면 학생이 덜 불안함. "서버에도 한도가 있다"는 것도 배움 |
